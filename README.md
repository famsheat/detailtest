# 🚗 Бот для записи клиентов (Детейлинг / Шиномонтаж / Автосервис)

## Что умеет бот:
✅ Принимает записи 24/7 без вашего участия
✅ Показывает клиенту свободное время
✅ Хранит профили клиентов (имя, телефон, авто)
✅ Присылает вам уведомления о каждой записи
✅ Показывает адрес с картой, галерею работ, услуги

---

## 📋 УСТАНОВКА (15 минут)

### Шаг 1: Создайте бота в Telegram
1. Откройте @BotFather в Telegram
2. Отправьте /newbot
3. Придумайте имя (например, "Мой Детейлинг")
4. Придумайте username (должен заканчиваться на bot)
5. **Сохраните TOKEN** — длинную строку типа `123456:AAH...`

### Шаг 2: Узнайте свой Telegram ID
1. Откройте @userinfobot
2. Нажмите Start
3. Скопируйте **ваш ID** (только цифры)

### Шаг 3: Настройте бота
Откройте файл `bot.py` и найдите блок:
НАСТРОЙКА БИЗНЕСА
Замените строки на свои:
- `TOKEN` — токен из шага 1
- `ADMIN_ID` — ваш ID из шага 2
- `BUSINESS_NAME` — название вашего бизнеса
- `ADDRESS` — ваш адрес
- `PHONE` — ваш телефон
- `SERVICES` — ваши услуги и цены

### Шаг 4: Запустите бота на сервере
1. Зарегистрируйтесь на https://railway.app (через GitHub)
2. Нажмите **+ New Project** → **Deploy from GitHub repo**
3. Выберите ваш форк репозитория
4. Нажмите **Deploy** — бот запустится за 1 минуту

### Шаг 5: Готово!
Откройте своего бота в Telegram, нажмите /start.
Добавьте свободное время командой: `/add 25.10 14:00`
